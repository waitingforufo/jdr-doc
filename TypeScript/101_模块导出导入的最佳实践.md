## 二、ES6模块 vs CommonJS模块对比

### 1. 语法与特性对比

| **特性**         | **ES6模块**                              | **CommonJS**                             |
|------------------|------------------------------------------|------------------------------------------|
| **导入方式**     | `import { User } from './user'`          | `const { User } = require('./user')`    |
| **导出方式**     | `export interface User { ... }`         | `module.exports = { User: ... }`         |
| **加载时机**     | **编译时**确定依赖关系                   | **运行时**动态加载                       |
| **Tree Shaking** | **支持**，可移除未使用代码               | **不支持**，必须加载整个模块             |
| **作用域**       | **文件级作用域隔离**                     | 全局作用域污染风险                       |
| **类型联动**     | **自动获得类型提示**                     | 需要额外类型声明                         |


### 2. 适用场景

**ES6模块（推荐）**：
- **现代浏览器环境**：原生支持ES模块
- **Node.js 12+**：通过`--experimental-modules`或`type: module`支持
- **前端框架**：React、Vue、Angular等均基于ES模块
- **TypeScript项目**：与TS类型系统完美集成<websource>source_group_web_7</websource>

**CommonJS（仅限旧项目）**：
- **旧版Node.js环境**（<12）
- **遗留项目**迁移过渡期
- **特定工具链**要求（如某些Webpack配置）

### 2. 模块导入导出规范

**导出规范**：
- **优先使用命名导出**：便于Tree Shaking和IDE跳转
- **默认导出仅用于主功能**：如React组件、配置对象
- **类型与运行时分离**：使用`export type`明确区分

**导入规范**：
- **明确导入路径**：使用相对路径（`./`或`../`）或绝对路径别名
- **按需导入**：避免`import * as`导致加载未用代码
- **类型与运行时分离**：

## 四、实际案例

```typescript
// src/models/user.ts
export interface User {
  id: number;
  name: string;
  email: string;
}

export function validateUser(user: User): boolean {
  return user.id > 0 && user.name.length > 0;
}

// src/services/userService.ts
import { User, validateUser } from '../models/user';

export class UserService {
  private users: User[] = [];
  
  addUser(user: User): void {
    if (validateUser(user)) {
      this.users.push(user);
    }
  }
  
  getUsers(): User[] {
    return this.users;
  }
}

// src/main.ts
import { UserService } from './services/userService';
import type { User } from './models/user';

const userService = new UserService();
userService.addUser({ id: 1, name: '张三', email: 'zhangsan@example.com' });
console.log(userService.getUsers());
```
